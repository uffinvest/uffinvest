# UFFinvest Hub

Site para uma liga de mercado financeiro chamada UFFinvest, com as cores: #1625b3 (Principal), #f8fbff (Cor Secundária) e #ebbf5c (Destaques).



Gere apenas o Frontend com dados fictícios e usuários fictícios, eu irei implementar o supabase no futuro. O site deve conter essas páginas:



Home:

Navbar Transparente com as páginas e botão para login/cadastro

Imagem principal cobrindo a tela toda

Pequeno resumo ”sobre nós”

Relatos de ex membros

Nossa equipe

Footer com links e Logos



Sobre Nós:

Missão, visão e Valores;

História da Liga



Projetos:

Carta Macro

Análise Macroeconômica

Análise Fundamentalista



Processo seletivo:

Informações de processos seletivos

Mensagem “nossos processos seletivos estão abertos” ou “no momento não estamos recrutando novos membros. Aguarde até o próximo processo seletivo”
